SINCRONIZZAZIONE OROLOGI - PRIMA DI UNA NUOVA SIMULAZIONE

Ferma l'orchestratore prima di correggere gli orologi.
Esegui una sezione alla volta sulla macchina indicata.
Non occorre impostare lo stesso fuso orario: deve coincidere l'ora UTC reale.
Questi comandi modificano/attivano la sincronizzazione oraria.

1. UBUNTU WAZUH MANAGER

Attiva il servizio di sincronizzazione disponibile nel sistema:

sudo timedatectl set-ntp true

Attendi circa un minuto, poi controlla:

timedatectl status

date -u --iso-8601=seconds

Cerca System clock synchronized: yes. NTP service: active da solo non prova
che l'orologio sia stato sincronizzato.
Se set-ntp segnala NTP not supported o la sincronizzazione resta no,
conserva l'output: serve verificare il servizio/sorgente disponibile.

2. WINDOWS-HR - WINDOWS POWERSHELL COME AMMINISTRATORE

Avvia il servizio Windows Time senza sostituire la sorgente gia configurata:

Start-Service -Name W32Time

Richiedi sincronizzazione con riscoperta della sorgente:

w32tm.exe /resync /rediscover

Attendi circa un minuto, poi verifica:

w32tm.exe /query /source

w32tm.exe /query /status

(Get-Date).ToUniversalTime().ToString('o')

Se Start-Service segnala che il servizio e disabilitato, oppure resync dice
che non sono disponibili dati di ora, non proseguire con il test:
comunica il messaggio e la sorgente restituita da query /source.
Non cambiare alla cieca i server NTP, i limiti di correzione o le policy del dominio.
Se Windows usa il controller di dominio, anche il suo orologio deve essere corretto.

3. CONFRONTO FINALE

Esegui a pochi secondi di distanza:

Su Ubuntu:

date -u --iso-8601=seconds

Su Windows PowerShell:

(Get-Date).ToUniversalTime().ToString('o')

Data, ore e minuti devono coincidere; i secondi differiranno del tempo
impiegato a passare tra le due console. Confronta anche con l'ora reale UTC.
Se restano ore di differenza, invia gli output prima di fare altre modifiche.

4. NUOVA PROVA




IDENTIFICARE LA SORGENTE ORARIA - COMANDI DI SOLA LETTURA

WINDOWS-HR - WINDOWS POWERSHELL

1. Verifica se la macchina appartiene a un dominio:

Get-CimInstance Win32_ComputerSystem | Select-Object Name, PartOfDomain, Domain

2. Mostra configurazione e sorgenti del servizio orario:

w32tm.exe /query /configuration

w32tm.exe /query /peers

UBUNTU WAZUH MANAGER - TERMINALE UBUNTU

3. Mostra la sorgente e lo stato del servizio systemd-timesyncd, se disponibile:

timedatectl timesync-status

Se il comando segnala che systemd-timesyncd non e disponibile, esegui:

systemctl list-units --type=service --all | grep -Ei 'timesync|chrony|ntp'

Inviare i risultati. Non impostare Ubuntu come server NTP di Windows senza
aver configurato un vero servizio NTP server: SSH e NTP sono servizi diversi.
Non sostituire la sorgente di dominio con server Internet prima di verificare
l'appartenenza al dominio e la raggiungibilita della sorgente autorizzata del laboratorio.

Solo dopo aver verificato l'allineamento, avvia una NUOVA sessione con AVVIA.cmd,
attendi il controllo iniziale, esegui i comandi di discovery e usa STOP.
La correzione non riscrive i timestamp delle sessioni o degli alert gia prodotti.
Controlla anche che config_hr.json abbia lo stesso agent_id degli alert Windows-HR.
