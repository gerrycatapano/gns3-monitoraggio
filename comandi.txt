SINCRONIZZAZIONE OROLOGI - PRIMA DI UNA NUOVA SIMULAZIONE

Ferma l'orchestratore prima di correggere gli orologi.
Esegui una sezione alla volta sulla macchina indicata.
Non occorre impostare lo stesso fuso orario: deve coincidere l'ora UTC reale.
Questi comandi modificano/attivano la sincronizzazione oraria.

1. UBUNTU WAZUH MANAGER

Attiva il servizio di sincronizzazione disponibile nel sistema:

sudo timedatectl set-ntp true

Attendi circa un minuto, poi controlla:

timedatectl status

date -u --iso-8601=seconds

Cerca System clock synchronized: yes. NTP service: active da solo non prova
che l'orologio sia stato sincronizzato.
Se set-ntp segnala NTP not supported o la sincronizzazione resta no,
conserva l'output: serve verificare il servizio/sorgente disponibile.

2. WINDOWS-HR - WINDOWS POWERSHELL COME AMMINISTRATORE

Avvia il servizio Windows Time senza sostituire la sorgente gia configurata:

Start-Service -Name W32Time

Richiedi sincronizzazione con riscoperta della sorgente:

w32tm.exe /resync /rediscover

Attendi circa un minuto, poi verifica:

w32tm.exe /query /source

w32tm.exe /query /status

(Get-Date).ToUniversalTime().ToString('o')

Se Start-Service segnala che il servizio e disabilitato, oppure resync dice
che non sono disponibili dati di ora, non proseguire con il test:
comunica il messaggio e la sorgente restituita da query /source.
Non cambiare alla cieca i server NTP, i limiti di correzione o le policy del dominio.
Se Windows usa il controller di dominio, anche il suo orologio deve essere corretto.

3. CONFRONTO FINALE

Esegui a pochi secondi di distanza:

Su Ubuntu:

date -u --iso-8601=seconds

Su Windows PowerShell:

(Get-Date).ToUniversalTime().ToString('o')

Data, ore e minuti devono coincidere; i secondi differiranno del tempo
impiegato a passare tra le due console. Confronta anche con l'ora reale UTC.
Se restano ore di differenza, invia gli output prima di fare altre modifiche.

4. NUOVA PROVA




IDENTIFICARE LA SORGENTE ORARIA - COMANDI DI SOLA LETTURA

WINDOWS-HR - WINDOWS POWERSHELL

1. Verifica se la macchina appartiene a un dominio:

Get-CimInstance Win32_ComputerSystem | Select-Object Name, PartOfDomain, Domain

2. Mostra configurazione e sorgenti del servizio orario:

w32tm.exe /query /configuration

w32tm.exe /query /peers

UBUNTU WAZUH MANAGER - TERMINALE UBUNTU

3. Mostra la sorgente e lo stato del servizio systemd-timesyncd, se disponibile:

timedatectl timesync-status

Se il comando segnala che systemd-timesyncd non e disponibile, esegui:

systemctl list-units --type=service --all | grep -Ei 'timesync|chrony|ntp'

Inviare i risultati. Non impostare Ubuntu come server NTP di Windows senza
aver configurato un vero servizio NTP server: SSH e NTP sono servizi diversi.
Non sostituire la sorgente di dominio con server Internet prima di verificare
l'appartenenza al dominio e la raggiungibilita della sorgente autorizzata del laboratorio.

Solo dopo aver verificato l'allineamento, avvia una NUOVA sessione con AVVIA.cmd,
attendi il controllo iniziale, esegui i comandi di discovery e usa STOP.
La correzione non riscrive i timestamp delle sessioni o degli alert gia prodotti.
Controlla anche che config_hr.json abbia lo stesso agent_id degli alert Windows-HR.


VERIFICA ACCESSO NTP DELLE VM - SOLO LETTURA

Non avviare ancora una nuova simulazione. Eseguire ciascuna sezione
solo sulla macchina indicata. Questi comandi non cambiano orologi o firewall.

WINDOWS-HR - WINDOWS POWERSHELL

1. Verifica risoluzione DNS IPv4 della sorgente gia configurata:

Resolve-DnsName time.windows.com -Type A

2. Richiedi cinque campioni NTP senza cambiare l'orologio:

w32tm.exe /stripchart /computer:time.windows.com /dataonly /samples:5

Nota: stripchart e il servizio Windows Time possono usare porte sorgenti diverse.
Un successo qui non garantisce da solo che il servizio resync funzioni.

UBUNTU WAZUH MANAGER - TERMINALE LINUX

3. Mostra gli indirizzi IPv4 della sorgente Ubuntu:

getent ahostsv4 ntp.ubuntu.com

4. Mostra i messaggi recenti del servizio di sincronizzazione:

sudo journalctl -u systemd-timesyncd -n 30 --no-pager

Inviare i risultati. Ubuntu al momento ha selezionato un indirizzo IPv6:
questo non dimostra da solo che IPv6 sia la causa.
Non usare Test-NetConnection -Port 123 per verificare NTP: quel controllo
prova TCP, mentre NTP utilizza UDP 123.
Start-Service e un comando Windows PowerShell, non Ubuntu.



CONFIGURAIZONE FINALE3 SEEE
CORREZIONE PERSISTENTE NTP - OPNSENSE DA CONSOLE

Eseguire SOLO nella console root di OPNsense, con orchestratore fermo.
Non usare PowerShell per i blocchi OPNsense.

Dalle regole mostrate, HR (vlan0.40) e Wazuh (vlan0.99) consentono TCP 123.
Il programma cambia in UDP le due regole NTP IPv4 di rete esistenti.
Conserva sorgenti, destinazioni, porte e NAT.
Inoltre rende persistente l'accesso SSH GIA ATTIVO:
10.0.40.13 -> 10.0.99.14 TCP 22. Lo aggiunge solo se riscontra esattamente
questa autorizzazione nel filtro attivo e se manca nella configurazione.
Serve per non perdere l'accesso SSH temporaneo al prossimo reload/riavvio.
Questa persistenza SSH e esplicita nel comando --keep-existing-ssh.

Il programma rifiuta di salvare se non trova esattamente una regola NTP
compatibile per ciascuna delle due interfacce. Non modifica regole di altre reti.
Esegue un backup di /conf/config.xml prima del salvataggio tramite il modello
nativo OPNsense. Conservare il percorso BACKUP mostrato.
Non e stato eseguito sul firewall: anteprima e verifiche sul posto sono necessarie.

1. DALLA SHELL ROOT OPNSENSE, ENTRA IN SH

/bin/sh

2. COPIA L'INTERO BLOCCO CHE SEGUE, DA cat FINO ALLA RIGA PHP COMPRESA

cat > /tmp/gns3_ntp_persistente.php <<'PHP'
<?php
// Run ONLY on the OPNsense console as root. Default mode is read-only.
require_once('script/load_phalcon.php');
use OPNsense\Core\Config;

function stop_now($message) {
    throw new RuntimeException($message);
}

$apply = in_array('--apply', $argv, true);
$keepSsh = in_array('--keep-existing-ssh', $argv, true);
$manager = null;
try {
    $manager = Config::getInstance();
    if ($apply) {
        $manager->lock();
    }
    $xml = $manager->object();
    $interfaces = [];
    foreach ($xml->interfaces->children() as $name => $entry) {
        $device = trim((string)$entry->if);
        if (in_array($device, ['vlan0.40', 'vlan0.99'], true)) {
            if (isset($interfaces[$device])) {
                stop_now('Interfaccia ambigua: ' . $device);
            }
            $interfaces[$device] = $name;
        }
    }
    if (count($interfaces) !== 2) {
        stop_now('Non trovate entrambe le interfacce vlan0.40 e vlan0.99. Nessuna modifica.');
    }
    $selected = [];
    $sshPersistent = false;
    foreach ($xml->filter->rule as $rule) {
        if (isset($rule->disabled)) {
            continue;
        }
        $iface = trim((string)$rule->interface);
        $proto = strtolower(trim((string)$rule->protocol));
        $port = strtolower(trim((string)$rule->destination->port));
        $type = strtolower(trim((string)$rule->type));
        $direction = strtolower(trim((string)$rule->direction));
        if ($type !== 'pass' || isset($rule->floating) ||
            !in_array($direction, ['', 'in'], true)) {
            continue;
        }
        if ($iface === $interfaces['vlan0.40'] && $proto === 'tcp' &&
            in_array($port, ['22', 'ssh'], true) &&
            trim((string)$rule->source->address) === '10.0.40.13' &&
            trim((string)$rule->destination->address) === '10.0.99.14' &&
            !isset($rule->source->not) && !isset($rule->destination->not)) {
            $sshPersistent = true;
        }
        foreach ($interfaces as $device => $logical) {
            if ($iface === $logical && in_array($proto, ['tcp', 'udp'], true) &&
                in_array($port, ['123', 'ntp'], true) &&
                trim((string)$rule->ipprotocol) === 'inet' &&
                trim((string)$rule->source->network) === $logical &&
                isset($rule->destination->any) &&
                !isset($rule->source->not) && !isset($rule->destination->not)) {
                $selected[$device][] = $rule;
            }
        }
    }
    foreach ($interfaces as $device => $logical) {
        if (count($selected[$device] ?? []) !== 1) {
            stop_now('Attesa una sola regola NTP IPv4 di rete su ' . $device . '. Nessuna modifica.');
        }
        $rule = $selected[$device][0];
        printf("NTP %s (%s): %s -> udp; porta e indirizzi invariati\n", $device, $logical, (string)$rule->protocol);
    }
    echo 'SSH persistente 10.0.40.13 -> 10.0.99.14:22: ' . ($sshPersistent ? 'presente' : 'assente') . "\n";
    if (!$apply) {
        echo "CHECK_OK. Solo anteprima: configurazione non salvata.\n";
        exit(0);
    }
    if (!$sshPersistent && !$keepSsh) {
        stop_now('SSH presente solo temporaneamente: usare --keep-existing-ssh per preservare lo stesso accesso.');
    }
    if (!$sshPersistent) {
        $lines = [];
        $code = 0;
        exec('/sbin/pfctl -sr 2>&1', $lines, $code);
        $found = false;
        foreach ($lines as $line) {
            if (preg_match('/^pass in quick on vlan0\.40 inet proto tcp from 10\.0\.40\.13 to 10\.0\.99\.14 port = (?:ssh|22)(?:\s|$)/', $line)) {
                $found = true;
            }
        }
        if ($code !== 0 || !$found) {
            stop_now('Regola SSH attiva attesa non trovata: nessun nuovo accesso viene creato.');
        }
    }
    $backup = '/conf/gns3-before-ntp-' . gmdate('Ymd-His') . '-' . bin2hex(random_bytes(3)) . '.xml';
    if (!copy('/conf/config.xml', $backup) || !chmod($backup, 0600)) {
        stop_now('Backup non riuscito. Nessun salvataggio.');
    }
    echo "BACKUP=$backup\n";
    foreach ($selected as $rules) {
        $rules[0]->protocol = 'udp';
    }
    if (!$sshPersistent) {
        $new = $xml->filter->addChild('rule');
        $new->addChild('type', 'pass');
        $new->addChild('interface', $interfaces['vlan0.40']);
        $new->addChild('ipprotocol', 'inet');
        $new->addChild('protocol', 'tcp');
        $new->addChild('direction', 'in');
        $new->addChild('log', '1');
        $source = $new->addChild('source');
        $source->addChild('address', '10.0.40.13');
        $destination = $new->addChild('destination');
        $destination->addChild('address', '10.0.99.14');
        $destination->addChild('port', '22');
        $new->addChild('descr', 'GNS3 preserve existing Windows-HR to Wazuh SSH access');
        $node = dom_import_simplexml($new);
        $firstRule = dom_import_simplexml($xml->filter->rule[0]);
        if ($node !== $firstRule) {
            $node->parentNode->insertBefore($node, $firstRule);
        }
    }
    if (!$manager->isValid()) {
        stop_now('Modello configurazione non valido. Nessun salvataggio.');
    }
    $manager->save(['description' => 'GNS3: correct HR/Wazuh NTP to UDP; preserve existing SSH access']);
    $manager->unlock();
    $disk = simplexml_load_file('/conf/config.xml');
    if ($disk === false) {
        stop_now('Verifica XML dopo salvataggio fallita. Ripristinare il backup dalla console.');
    }
    echo "CONFIG_SAVED. Ora applicare con configctl filter reload e verificare le regole attive.\n";
} catch (Throwable $error) {
    if ($manager !== null && $apply) {
        $manager->unlock();
    }
    fwrite(STDERR, 'ERRORE: ' . $error->getMessage() . "\n");
    exit(1);
}
PHP

3. CONTROLLO SINTASSI E ANTEPRIMA (NON SALVANO LA CONFIGURAZIONE)

php -l /tmp/gns3_ntp_persistente.php

php /tmp/gns3_ntp_persistente.php

Proseguire SOLO se compare CHECK_OK e le due interfacce sono quelle attese.
Se compare ERRORE, fermarsi e inviare il risultato.

4. SALVA LE CORREZIONI E PRESERVA L'ACCESSO SSH ESISTENTE

php /tmp/gns3_ntp_persistente.php --apply --keep-existing-ssh

Proseguire SOLO se compare CONFIG_SAVED.
Annotare il percorso BACKUP stampato. Il backup contiene segreti del firewall:
non caricarlo su GitHub e non pubblicarne il contenuto.

5. RIGENERA E APPLICA LE REGOLE DALLA CONFIGURAZIONE PERSISTENTE

configctl filter reload

6. VERIFICA LE REGOLE REALMENTE ATTIVE

pfctl -sr | grep -E 'on vlan0[.](40|99).*proto udp.*port = (ntp|123)'

Devono comparire le due regole pass in quick UDP NTP, una per interfaccia.

pfctl -sr | grep -F 'from 10.0.40.13 to 10.0.99.14 port = ssh'

Se non compare SSH con nome simbolico, verificare anche il numero:

pfctl -sr | grep -F 'from 10.0.40.13 to 10.0.99.14 port = 22'

pfctl -sn

Verificare che il NAT delle reti vlan0.40 e vlan0.99 sia ancora presente.
Il solo messaggio OK del reload non e prova sufficiente: guardare le regole.

7. WINDOWS-HR - WINDOWS POWERSHELL COME AMMINISTRATORE

w32tm.exe /stripchart /computer:time.windows.com /dataonly /samples:5

Se riceve campioni senza timeout:

w32tm.exe /resync /rediscover

w32tm.exe /query /status

8. UBUNTU WAZUH - TERMINALE LINUX

sudo systemctl restart systemd-timesyncd

timedatectl timesync-status

timedatectl status

date -u --iso-8601=seconds

Attendere la sincronizzazione prima di una nuova simulazione.
La correzione permette IPv4: se Ubuntu sceglie ancora un indirizzo IPv6
irraggiungibile, potrebbe essere necessario configurare una sorgente IPv4
per timesyncd. Non disabilitare IPv6 globalmente.
Se anche IPv4 continua in timeout, verificare il percorso a monte del firewall.
Non promettiamo che questa correzione elimini eventuali ulteriori blocchi esterni.

RIPRISTINO SOLO IN CASO DI PROBLEMI - DALLA CONSOLE ROOT OPNSENSE

Usare il percorso BACKUP esatto stampato dal programma al punto 4.
Sostituire NOME_ESATTO prima di eseguire:

cp -p /conf/gns3-before-ntp-NOME_ESATTO.xml /conf/config.xml

configctl filter reload

Il backup riporta la configurazione persistente precedente: se SSH prima era
solo temporaneo, il backup non lo contiene. La console GNS3 resta il punto di recupero.
Non ricaricare i vecchi file /tmp/rules.* dopo il successo della correzione:
riporterebbero il filtro attivo alla situazione precedente.
